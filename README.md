# Feuerwehr Wien – Mitgliederportal

Login, Einsatzberichte, Beförderungen und Verwaltung (Firebase Auth + Firestore).

1. Firebase-Config in `public/index.html` eintragen (`firebaseConfig`).
2. Inhalt von `firestore.rules` in der Firestore-Konsole unter "Regeln" einfügen.
3. Lokal starten: `npm install && npm start` → http://localhost:3000
4. Auf Render: Repo verbinden, `render.yaml` wird automatisch erkannt.
5. Deine Render-Domain unter Firebase → Authentication → Einstellungen → Autorisierte Domains eintragen.
